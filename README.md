# JK-s-Homey-Hotel

First Build GUI was initially to be created using JavaFX - however, during the first stages of programming it was found to be difficult (SDK linking was refusing to pair and function) to be set up in order to have a functioning database so the decision was made to instead go with Swing. 
A sacrifice was made for modern visuals in order to have a database that was funcitoning and could be set up in the first place. 
In the end, Swing was selected over JavaFX due to its native integration with Java, ensuring zero configuration overhead and faster development while still meeting all GUI requirements.
